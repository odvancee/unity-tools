## OpenGitBash

### Concept

Opens Git Bash in the project root directory.

Make sure to add git to the PATH.

### Features

- Open a new Git Bash window
- Focus an existing Git Bash window
- Finds Git in the PATH

### Usage

- Menu: Assets > Open Git Bash
- Menu: Tools > Git Bash
- Shortcut: `Ctrl + G` (Focus an existing window or create a new one)
- Shortcut: `Ctrl + Alt + G` (Create a new window)

### Limitations

- No support for Mac/Linux terminals
- Unstable workflow with several bashes opened
